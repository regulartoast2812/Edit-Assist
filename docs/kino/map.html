00:06A job's life

The same states for both services. A desktop app has no public address, so Kino checks on jobs (polls) instead of waiting for webhooks.

  2. Checkthe model's limits and the costbreaks a limit: back to Draft, nothing spent
  3. Uploadyour files to a link the service can readKling has no upload
  4. Submitwith a key against double chargesbusy: wait and try again
  5. Running1–5 min on Kling, 30 s–10 min on Higgsfieldfailed, or blocked by moderation
  6. Donelinks expire7 days Higgsfield, 30 days Kling
  7. Saveddownloaded next to the project

00:07Writing the prompt

Kling 4.0's official structure and Higgsfield's cinematic guide agree, so one template serves both.

[Asset roles]@hero is the character: keep face, hair and outfit. @kitchen is the place: keep its layout. Follow the camera path of @walk; don't carry over its people.
[Overall]Scene and texture, visual style, camera tone.
[Timeline]0–3 s: … · 3–7 s: camera + action + emotion · 7 s–end: closing shot.
[Audio]Who says what, in quotes, in the target language, with age, tone and pace; ambience; music; effects.
[Exclusions]No subtitles, no background music. Kling adds both unless told not to.
  • Describe, don't judge. "Side backlight outlines the edges", not "premium feel". Say what you want; most models have no negative prompt.
  • Image → video describes motion only. The frame already shows the look.
  • To change a clip, write "Edit @clip". "Reference" sends it down a different pipeline.
  • Keyframes: for a start frame say what happens next; for an end frame, the path into it.
  • Leave duration empty and Kling 4.0 reads it from the prompt ("a 15-second video").
  • Change one thing at a time; draft cheap at 720p, then re-render the same prompt.
  • Storyboard sheets: ask for finished frames, or grid lines and labels leak into the video.

00:09Open questions

1

Which accounts exist? Both APIs bill separately from the web plans. Kling 4.0 on the API needs a Flagship resource pack; Higgsfield's API is a separate account with a dollar balance.

2

Kling direct, Higgsfield, or both? Direct gives every Kling 4.0 field, Elements, Voices and lip sync. Higgsfield gives one key for many models, uploads, estimates and a lower listed Kling 4.0 price, but no 4.0 fields yet.

3

Where do your clips live for Kling? It needs a public URL for every video input.

4

Unsettled in the docs: Kling 4.0's web credit price, 4K for 4.0, Higgsfield's concurrency for a new key (2 or 20), DoP on Higgsfield's API (treated as no).

Full sourced notes: docs/kino/README.md, kling.md, higgsfield.md in the Edit Assist repo. Both services change monthly; recheck a limit before code depends on it.
